# BIL-001 : Créer les squelettes des services métier

- **Branche** : `chore/bil-001-squelettes-services`
- **Dépend de** : BIL-F25
- **Service** : infra

## Objectif

Créer les squelettes vides de Catalogue, Billets, Commandes, Paiements et Notifications en
reprenant la structure du service echo.

## Étapes

- [x] 1. Pour chaque service (`catalogue`, `billets`, `commandes`, `paiements`, `notifications`) :
  copier la structure de `services/echo`, renommer, garder seulement `/health`.
- [x] 2. Tags Consul et préfixes de routes : `/api/v1/events`, `/api/v1/seats`, `/api/v1/orders`,
  `/api/v1/payments`, `/api/v1/notifications`.
- [x] 3. Une base par service (créée par BIL-F05), une migration Alembic initiale vide.
- [x] 4. Billets et Commandes en deux instances dans le compose.
- [x] 5. Ajouter chaque service à la CI et au tableau de bord Grafana.

## Critères d'acceptance

- [x] CA1 : `make up` démarre les cinq services, tous verts dans Consul
- [x] CA2 : chaque `/health` répond via Traefik
- [x] CA3 : la CI couvre les cinq services

## Contraintes

- Aucune logique métier dans ce ticket.
