En tant que client, je veux attendre mon tour dans une salle d'attente à l'ouverture des ventes,
plutôt que de voir le site saturer.

## Décisions

- Mode allégé (2026-11-14) : pas de nouveaux tests ; scripts k6 écrits, mesures faites par le
  développeur (plateforme démarrée, charge locale).
- Décision du développeur (2026-11-14) : l'admission est vérifiée **dans Commandes**
  (`creerCommande` exige un jeton d'admission signé par `file-attente` pour une séance en vente
  sous file) ; Billets ne change pas. Écart à la lettre de l'étape 3, qui citait Billets.
- Nouveau service généré depuis le modèle `services/echo/`.
- Contrat (recommandations retenues) : ressource `queues`, `POST|GET
  /api/v1/queues/{seance_id}/position` (`entrerFile` idempotent, `lirePositionFile`), rôle
  `customer`, `PositionFile` (EN_ATTENTE avec position et estimation, ADMIS avec jeton et
  expiration), santé par Redis. Commandes : en-tête `X-Admission-Token` sur `creerCommande`,
  403 `ADMISSION_REQUIRED` / `ADMISSION_INVALID`, contrôle avant tout verrou, signature vérifiée
  localement ; `payerCommande` inchangée.
- Séances sous file : variable `SEANCES_SOUS_FILE` (file-attente et Commandes) ; hors liste :
  404 `QUEUE_NOT_FOUND`. Jeton HMAC (clé partagée, séance, `sub`, expiration), 10 min
  configurables, réutilisable jusqu'à expiration. Vagues : taille et intervalle en variables ;
  estimation `ceil(position / taille) × intervalle`. Admission expirée : sortie de file.
- Review (`docs/reviews/BIL-015.md`) : 1 bloquant (types du front non régénérés) et 3 à
  corriger traités (section du modèle de données, commentaires d'alias retirés : le test de
  contrat traduit `-` en `_`). CA2 attend les tirs k6 du développeur. Le front ne peut pas
  acheter une séance sous file avant BIL-023 (salle d'attente).
- Hors ticket : comptes clients de test multiples pour k6 (realm), rejeu idempotent soumis à
  l'admission, `sub` contenant `|`, lecture de `SEANCES_SOUS_FILE` en double.
- Risque accepté : les revendeurs (`partner`) ne passent pas par la file (quota 429 seulement).
