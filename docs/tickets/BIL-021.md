## Objectif

En tant que client, je veux payer mes places, voir la confirmation et retrouver mes billets avec
leur QR code.

## Étapes

- [ ] Récapitulatif de commande et paiement simulé (succès ou refus).
- [ ] Clé d'idempotence générée côté front pour éviter le double paiement au double clic.
- [ ] Page de confirmation, puis « Mes billets » avec QR code.
- [ ] Message clair si la commande a expiré.

## Critères d'acceptance

| #   | Critère                                                   |
| --- | --------------------------------------------------------- |
| CA1 | Un double clic sur Payer ne crée qu'un paiement            |
| CA2 | Les billets s'affichent avec leur QR code après paiement   |

## Contraintes

- Aucune donnée de carte réelle, paiement simulé uniquement.
