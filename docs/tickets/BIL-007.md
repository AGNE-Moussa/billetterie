# BIL-007 : Test de concurrence : jamais deux ventes de la même place

- **Branche** : `test/bil-007-concurrence`
- **Dépend de** : BIL-006
- **Service** : billets (tests)

## Objectif

Prouver par un test automatisé que 100 clients simultanés sur la même place produisent exactement
une vente.

## Étapes

- [ ] Test d'intégration asynchrone qui lance 100 verrouillages simultanés sur la même place.
- [ ] Vérifier : un seul succès, 99 refus `SEAT_ALREADY_TAKEN`.
- [ ] Second test en contournant Redis : la contrainte en base doit seule empêcher la double vente.
- [ ] Ajouter le test à la CI.

## Critères d'acceptance

| #   | Critère                                                       |
| --- | ------------------------------------------------------------- |
| CA1 | Exactement une vente sur 100 tentatives, dix exécutions de suite |
| CA2 | Sans Redis, la base refuse quand même la double vente         |

## Contraintes

- Test sur un vrai PostgreSQL et un vrai Redis, jamais sur des simulacres.
